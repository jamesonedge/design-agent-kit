Library: choose a direction

Illustrative synthetic example. All three directions use the same task, constraints, tokens and synthetic data. Production mode: serial, one agent (not independent designers).

A — Sections

Keep the single list; add search, status filters and "Continue reading / This week / Last week / Earlier" headings.

B — Next up

Answer "what should I read now?" with one recommended item for the time available; the full list moves behind a link.

C — Board

Three status columns (To read, Reading, Done) with explicit "Move" buttons; columns scroll sideways on phones.

Trade-offs against the complaint: "I can never find what I saved last week, and I can't tell what I'm halfway through."
