# Changelog

All notable changes are recorded here. The project uses [semantic versioning](https://semver.org/).

## 0.1.0 — 2026-11-01

### Added

- `senior-design-review` skill with proposal, review and context templates, review lenses and an accessibility/i18n checklist.
- `interactive-mockup` skill with direction brief, static direction, comparison and change-ledger templates, strict graft rules and a prototype quality gate.
- Root documentation: README with bootstrap prompt, AGENTS protocol, prompts, compatibility, project context form, quality checklist and security notes.
- `scripts/install.py`: optional standard-library installer that copies local files, refuses conflicting trees and prints a hash receipt.
- `scripts/validate.py`: static checks for frontmatter, version consistency, local links, bundled files and simple public-safety patterns.
- Synthetic `examples/reading-list/` walk-through.
